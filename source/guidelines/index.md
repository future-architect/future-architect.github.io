# フューチャーのガイドライン

フューチャーが無償公開している設計ガイドライン・コーディング規約・学習コンテンツの入口です。いずれも現場のプロジェクトで培った知見を有志がまとめ、継続的に更新しています。

## 設計ガイドライン（Future Architecture Guidelines）

<https://future-architect.github.io/arch-guidelines/>

Web API・Terraform・ログ・バッチ・PostgreSQL・非同期処理・データマネジメントなど、システム設計の指針を領域別にまとめたガイドライン集です。ソフトスキルや性能テスト入門などの読み物も含みます。

- [2025年の振り返り（15本を作成してみてどうだったか）](/articles/20260123a/)
- [2026年の公開スケジュール](/articles/20260216a/)

## コーディング規約（Future Enterprise Coding Standards）

<https://future-architect.github.io/coding-standards/>

エンタープライズ領域に特化したコーディング規約です。Java・SQL などの言語規約と、Gitブランチフローなどの開発プロセス規約を含みます。

## 仕事ですぐに使えるTypeScript

<https://future-architect.github.io/typescript-guide/>

JavaScript を経由せず、最初から TypeScript でウェブフロントエンド開発を学ぶための教育コンテンツです。
